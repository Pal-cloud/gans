Paso 1 de 6

Como funciona una GAN

Sin codigo y sin matematicas. Sigue el ciclo paso a paso usando la metafora del falsificador y el detective. Cada paso del ciclo corresponde a una operacion real del algoritmo.

🔑
La idea central: dos redes neuronales compiten entre si. Una aprende a crear, la otra aprende a detectar. La competencia es lo que hace que ambas mejoren sin necesidad de instrucciones explicitas sobre como hacerlo bien.

Glosario basico

Espacio latente (z)
Vector de numeros aleatorios que sirve de "semilla" para el Generador. Cada punto del espacio latente corresponde a una muestra diferente.
Perdida (loss)
Numero que mide lo mal que lo esta haciendo una red. El objetivo del entrenamiento es minimizarla ajustando los pesos internos.
Backpropagation
Algoritmo que calcula cuanto ha contribuido cada peso al error y en que direccion hay que ajustarlo para reducirlo.
Equilibrio de Nash
Punto teorico donde ninguno de los dos jugadores puede mejorar su resultado cambiando solo su propia estrategia. En una GAN: el Discriminador acierta el 50%.
Colapso de modo
Fallo tipico: el Generador aprende a producir siempre la misma muestra porque engana al Discriminador, perdiendo diversidad.
Epoca (epoch)
Una pasada completa por todo el conjunto de datos de entrenamiento. Un entrenamiento tipico requiere decenas o cientos de epocas.

Paso 2 de 6

Arquitectura de una GAN

Diagrama del flujo completo de datos. Cada flecha representa una operacion matematica; el color indica quien "posee" ese tramo del calculo.

🔎
Como leer el diagrama: el flujo hacia la derecha es la pasada hacia adelante (forward pass): el Generador crea, el Discriminador evalua. La flecha dorada vuelve hacia atras (backward pass): es el gradiente de error que le dice al Generador como mejorar.
Generador: convierte ruido en muestras sinteticas
Discriminador: distingue muestras reales de generadas
Gradiente: la senal de error que guia el aprendizaje

Esquema del flujo

Ruido z numeros aleatorios
→
Generador G transforma el ruido
→
Discriminador D evalua real/falso
→
Perdida mide el error
→
Actualizacion mejora los pesos
gan_minimal.py — Python 3 + PyTorch 
import torch, torch.nn as nn       # libreria de redes neuronales

# ── 1. GENERADOR: el falsificador ─────────────────────────────────
class G(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(100, 256), nn.ReLU(),   # ruido -> espacio interno
            nn.Linear(256, 784), nn.Tanh()    # espacio interno -> imagen 28x28
        )
    def forward(self, z): return self.net(z)

# ── 2. DISCRIMINADOR: el detective ────────────────────────────────
class D(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(784, 256), nn.LeakyReLU(0.2),  # imagen -> analisis
            nn.Linear(256, 1),   nn.Sigmoid()        # analisis -> prob. de ser real
        )
    def forward(self, x): return self.net(x)

# ── 3. INSTANCIAR REDES Y OPTIMIZADORES ───────────────────────────
g, d   = G(), D()
opt_g = torch.optim.Adam(g.parameters(), lr=2e-4)  # optimizador del falsificador
opt_d = torch.optim.Adam(d.parameters(), lr=2e-4)  # optimizador del detective
loss  = nn.BCELoss()                                 # funcion de perdida binaria

# ── 4. BUCLE DE ENTRENAMIENTO ─────────────────────────────────────
for epoch in range(50):
    # -- Entrenar el Discriminador (el detective) --
    z         = torch.randn(64, 100)          # 64 vectores de ruido aleatorio
    falso     = g(z).detach()                 # generar sin propagar al G
    d_loss    = loss(d(real), ones) + loss(d(falso), zeros)  # detectar bien
    opt_d.zero_grad(); d_loss.backward(); opt_d.step()

    # -- Entrenar el Generador (el falsificador) --
    z         = torch.randn(64, 100)          # nuevo ruido
    g_loss    = loss(d(g(z)), ones)            # enganar al detective
    opt_g.zero_grad(); g_loss.backward(); opt_g.step()
Generador — el falsificador 
# El Generador transforma RUIDO en una MUESTRA sintetica.
# Entrada: vector z de 100 numeros aleatorios (espacio latente)
# Salida:  vector de 784 valores = imagen 28x28 aplanada

class Generator(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            # Capa 1: expande el ruido a un espacio mas rico
            nn.Linear(100, 256),
            nn.ReLU(),          # activa solo valores positivos

            # Capa 2: proyecta al tamano de la imagen
            nn.Linear(256, 784),
            nn.Tanh()           # normaliza salida entre -1 y 1
        )

    def forward(self, z):
        return self.net(z)   # aplicar todas las capas en orden

# Uso:
g = Generator()
z = torch.randn(1, 100)   # un vector de ruido
imagen = g(z)               # una imagen sintetica 28x28
Discriminador — el detective 
# El Discriminador decide si una imagen es REAL o GENERADA.
# Entrada: vector de 784 valores = imagen 28x28 aplanada
# Salida:  un numero entre 0 (falso) y 1 (real)

class Discriminator(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            # Capa 1: analiza las caracteristicas de la imagen
            nn.Linear(784, 256),
            nn.LeakyReLU(0.2),   # permite gradiente negativo pequeno
            nn.Dropout(0.3),      # evita sobreajuste apagando neuronas

            # Capa 2: decision final
            nn.Linear(256, 1),
            nn.Sigmoid()           # comprime a rango [0, 1]
        )

    def forward(self, x):
        return self.net(x)   # aplicar todas las capas en orden

# Uso:
d = Discriminator()
prob = d(imagen_real)    # deberia devolver ~1.0
prob = d(imagen_falsa)   # deberia devolver ~0.0 al inicio
Bucle de entrenamiento — el corazon del algoritmo 
# Este bucle se repite 50 veces (50 epocas).
# En cada epoca, el D y el G se turnan para mejorar.

for epoch in range(50):
    for imagenes_reales in dataloader:   # recorrer datos reales por lotes

        # ── TURNO DEL DISCRIMINADOR (el detective) ──────────────
        z     = torch.randn(64, 100)         # ruido para el generador
        falsas = g(z).detach()              # generar sin afectar al G

        # perdida = error al clasificar reales + error al clasificar falsas
        d_loss = (loss(d(imagenes_reales), ones)
                 + loss(d(falsas), zeros)) / 2

        opt_d.zero_grad()    # limpiar gradientes anteriores
        d_loss.backward()    # calcular nuevos gradientes
        opt_d.step()          # actualizar pesos del D

        # ── TURNO DEL GENERADOR (el falsificador) ───────────────
        z      = torch.randn(64, 100)        # nuevo ruido
        falsas = g(z)

        # el G quiere que D clasifique sus falsas como reales (ones)
        g_loss = loss(d(falsas), ones)

        opt_g.zero_grad()    # limpiar gradientes anteriores
        g_loss.backward()    # calcular nuevos gradientes
        opt_g.step()          # actualizar pesos del G

    print(f"Epoca {epoch+1} | D: {d_loss:.3f} | G: {g_loss:.3f}")

Paso 6 de 6

Dominios de aplicacion

Las GANs no son una sola tecnica: son una familia de arquitecturas adaptadas a cada tipo de dato. Imagenes, texto y audio requieren enfoques distintos.

Las imagenes son datos continuos con estructura espacial regular, ideales para GANs convolucionales. Hoy existen caras sinteticas indistinguibles de fotografias reales.

Arquitecturas principales

DCGANArquitectura base con convoluciones. Genera imagenes coherentes.
StyleGAN 2/3Control fino del estilo a distintas escalas. Imagenes fotorrealistas.
Pix2PixTransformacion condicionada: boceto a fotografia, mapa a satelite.
CycleGANTransformacion sin pares de entrenamiento: caballos a cebras.
SRGANSuper-resolucion: aumentar la resolucion con detalles plausibles.

Desafios

1Inestabilidad durante el entrenamiento
2Colapso de modo: el generador produce variedad reducida
3Evaluacion objetiva de la calidad visual

El texto es discreto: no existe nada entre la palabra "gato" y la palabra "perro". Esto impide el flujo directo del gradiente, por lo que se necesitan tecnicas especiales.

Arquitecturas principales

SeqGANUsa Monte Carlo Tree Search para estimar el gradiente sobre secuencias discretas.
TextGANTrabaja en el espacio continuo de embeddings para permitir el flujo de gradiente.
MaskGANRellena partes enmascaradas de un texto de forma coherente con el contexto.
Trans-GANCombina la arquitectura Transformer con el esquema adversarial.

Desafios

1La no diferenciabilidad de la seleccion de palabras discretas
2Dificultad para mantener coherencia a largo plazo
3Los LLMs modernos han superado a las GANs en la mayoria de tareas de texto

El audio puede tratarse como forma de onda 1D o transformarse en un espectrograma 2D. La segunda aproximacion reutiliza directamente las tecnicas de imagenes.

Arquitecturas principales

WaveGANOpera directamente sobre la forma de onda con convoluciones 1D.
MelGANGenera espectrogramas Mel tratando el audio como una imagen 2D.
HiFi-GANVocoder de alta fidelidad con multiples discriminadores a distintas escalas.
MuseGANGeneracion musical polifonica: coordina multiples instrumentos.

Desafios

1La coherencia temporal: el oido detecta discontinuidades que el ojo ignora
2Secuencias muy largas: 44.100 muestras por segundo en calidad CD
3Artefactos sonoros como clicks y distorsion son muy perceptibles
